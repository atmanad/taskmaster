# **App Name**: TaskMaster

## Core Features:

- Date Based Task List: User can add/remove tasks to a list that is date based and persists in a database.
- Global Task List: User can add/remove tasks to a list that is not date based and persists in a database.
- Task Status: Visually separate complete tasks from incomplete tasks.

## Style Guidelines:

- Primary color: Light blue (#E0F7FA) for a calm and focused feel.
- Secondary color: Gray (#B0BEC5) for general UI elements.
- Accent: Teal (#009688) for task completion and important actions.
- Divide the page into two distinct sections: one for date-specific tasks and another for global tasks.
- Use clear and recognizable icons for task completion (checkbox) and deletion (trash icon).
- Subtle transition animations when marking tasks as complete or deleting them.
